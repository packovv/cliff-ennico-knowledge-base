# Учебная база идей Cliff Ennico

База помогает изучать предпринимательские идеи по английским расшифровкам и обсуждать их с ИИ на русском. Передайте папку своему ИИ-агенту и попросите прочитать `AGENTS.md`: он сам выбирает способ чтения или поиска, проверяет цитирование и сообщает ограничения своей среды. Это переносимый комплект, не API, который автоматически поддерживает любой сервис.

## Подключение через агента

1. Предоставьте агенту доступ к этой папке или файлам средствами своего сервиса. Один путь к локальной папке не даёт облачному агенту доступа к диску.
2. Попросите: «Прочитай AGENTS.md в предоставленной базе Cliff Ennico. Сам выбери способ подключения, проверь поиск и точные цитаты, сообщи доступные источники и ограничения. Работай только на чтение; установку, постоянный индекс и передачу файлов во внешний сервис согласуй отдельно».
3. Агент проверит подключение, затем уточнит вашу учебную цель и начнёт работу. Вам не нужно заранее выбирать эмбеддинги, векторную базу, MCP или формат индекса.

`AGENTS.md` не во всех сервисах читается автоматически, поэтому явно укажите его как точку входа. Если агент не имеет доступа к файлам, он должен назвать нужный способ предоставления доступа, а не заявлять, что база подключена.

## Если агент недоступен

В обычном чате с вложениями используйте `AI_INSTRUCTIONS.md` как правила ответа, добавьте каталог и несколько TXT нужной темы. Для последовательного обучения добавьте `curriculum.md`. Проверяйте цитаты по исходным файлам и сценариям из `learning-checks.md`. При отсутствии загрузки файлов и поиска работа с локальной папкой невозможна без предоставления её текста доступным способом.

Не загружайте `build_kb.py`, `manifests/`, `tests/`, скрытые файлы `.*` (включая `._*`), журналы и технические отчёты как учебные источники. `taxonomy.md` можно добавить для фильтров; `source-metadata.csv` нужен только для контроля происхождения. У сервисов разные способы поиска и разные лимиты: успешная загрузка не гарантирует извлечение всех источников.

## Как устроена база

- `AGENTS.md` задаёт переносимый протокол подключения, проверки доступа, поиска и цитирования без обязательной индексации.
- `AI_INSTRUCTIONS.md` задаёт учебный режим после подключения; это инструкции, не источник тезисов автора.
- `Transcriptions/` содержит неизменённые первичные TXT. Генератор только читает их, игнорируя скрытые пути.
- `catalog.csv` хранит устойчивые ID, путь, предварительные теги, статус метаданных, сигналы права и точные цитаты этих сигналов.
- `chunks.jsonl` содержит производные фрагменты примерно до 4000 символов, без перекрытия и потери текста. `char_start` включён, `char_end` исключён; это позиции Unicode-символов в точно декодированном UTF-8 тексте, не байты и не секунды.
- `source-metadata.csv` хранит редактируемые человеком сведения о происхождении: 1 confirmed и 52 candidate. URL и даты кандидатов остаются только в этой таблице; каталог публикует эти поля только для confirmed. Правила статусов описаны в `taxonomy.md`.
- `source-research.md` сохраняет переданные результаты публичного исследования, карту видео, доказательство совпадения вступления `019` и причину остановки проверки остальных расшифровок.
- `review-report.md` показывает последний структурный контроль, счётчики метаданных и изменения относительно предыдущего манифеста; `validation-report.md` отделяет одобренную техническую проверку предыдущей версии от текущих тестов и статусов исследования.

Ссылка на фрагмент имеет вид «имя исходного файла; chunk_id; точная цитата». При загрузке оригинального TXT используйте имя файла и точную цитату без выдуманного chunk_id. SHA256 позволяет установить версию текста. При неизменных тексте, ID и алгоритме фрагменты воспроизводимы; редактирование текста может сдвинуть границы следующих фрагментов. Таймкоды не восстановлены. Автоматическое разбиение не исправляет ошибки распознавания речи, не восстанавливает слайды, говорящих и пропущенную информацию.

## Учебные ограничения

Комплект не является проверенным конспектом всех выступлений или справочником действующего права; теги предложены по названиям.

Обсуждение американских правовых механизмов и исторических условий не означает их актуальность сегодня или применимость в другой стране. `published_at` означает дату публикации/upload_date видео, не дату записи. Для практического решения отдельно проверяйте дату, юрисдикцию и действующие правила; учебный ответ не заменяет профессиональный совет.

## Необязательная командная строка

Нужен только Python 3 со стандартной библиотекой. Все команды можно запускать из любой папки; ниже пути к переносимой папке базы должны соответствовать её расположению.

Это обслуживание производных файлов, не подключение к ИИ. Для обычного чтения и обучения запуск генератора не нужен. Агент не должен выполнять эти команды без отдельного разрешения на изменения базы.

```sh
python3 -B "/путь/к/базе/build_kb.py"
python3 -B -m unittest discover -s "/путь/к/базе/tests" -v
```

Первый запуск требует `Transcriptions/`, `taxonomy.md` и существующую папку `manifests/`; копируйте базу целиком. Не переносите генератор отдельно к произвольному набору файлов. При восстановлении копии сохраняйте каталог, метаданные и манифесты, чтобы не потерять ID и историю.

Генератор валидирует входы и производные данные до замены результатов. Каждый выходной файл заменяется атомарно, но весь набор не является одной транзакцией. Если запись прервана, повторите запуск и проверьте соответствие текущего `manifest_id` в активном каталоге и отчёте; ошибка не означает успешное завершение. Старые манифесты не удаляются, таксономия и документы обучения не перезаписываются.

ID сохраняется по точному пути. Новый путь получает номер больше всех известных; исчезнувший архивируется. Автоматического распознавания переименований нет: перенос файла создаёт новый ID и архив старого, даже при одинаковом хеше. Не объединяйте записи по совпадению текста без отдельной проверки. Подтверждённые метаданные меняйте в `source-metadata.csv`, а не в генерируемых колонках каталога.
